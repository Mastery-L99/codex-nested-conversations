# 常见问题

## 和桌面端「已创建的聊天」有什么区别？

在官方桌面包 `26.1027.3384.0` 中，单个聊天的摘要里已经能展开「已创建的聊天」。想从主聊天快速回到它创建的聊天，可以先用这个入口。Codex 的 `/side` 也能发起临时侧聊。项目插件的目录可跨主聊天搜索、按父子关系展开多级，并在聊天旁显示。原项目和最近列表里的折叠树属于可选的完整增强。[官方命令说明](https://learn.chatgpt.com/docs/developer-commands#start-a-side-chat-with-side)

## 安装以后，官方还能检查更新吗？

这两个模块通过应用外的目录和官方插件登记工作。官方程序仍由 Windows 商店管理。本机在安装早期嵌套增强之后，商店曾把客户端从 `26.1023.6621.0` 成功升级至 `26.1027.3384.0`。独立归档插件和新版嵌套面板是在这次更新后安装的。

## 官方更新后，目录会消失吗？

正常更新会重启客户端，当前窗口里的侧栏增强也随进程结束。插件安装目录在商店包外，更新后先从原图标进入，打开「嵌套对话」并展开一组已知父子聊天。使用原列表增强时，从增强入口启动再检查同一组。官方如果调整插件接口、聊天存储或侧栏结构，某一入口可能需要新版适配。安装器的 `--check` 可读取当前官方包版本、插件版本和启用状态，实际展开和跳转需要在窗口里检查。核查更新无需对真实聊天试做归档。

适用于 `0.3.0-preview.6`。安装步骤见 [Windows 快速开始](quickstart.zh-CN.md)。

## doctor 提示缺少依赖或官方应用怎么办？

先在解压后的项目根目录运行 `npm ci --ignore-scripts`，再运行 doctor。确认 Node.js 22+、npm 和 Python 3.10+ 已安装，重新打开 PowerShell 后执行 `node --version`、`npm --version`、`python --version` 检查；Python 也可通过 Windows 的 `py` 启动器被检测。doctor 查找已安装的官方 Codex 包；未能唯一定位时，请检查官方应用是否已正确安装。脚本不会替你下载工具，也不会启动应用。

## 安装提示目录或快捷方式已存在？

安装器不会覆盖已有程序目录或同名桌面快捷方式。先确认是否已有本项目安装；要升级，按快速开始的卸载和 `-ReuseData` 步骤操作。数据目录已经存在时，只有带本项目身份标记的数据目录才能用 `-ReuseData` 复用。安装中断留下有标记的半成品时，可以使用源码目录的卸载脚本预览并处理；不要删除不属于本项目的文件。

## 启动后还是普通列表？

普通官方入口可能绕过增强，包括固定的官方开始菜单图标。先通过 Codex 的 **文件 → 退出** 正常退出，再运行增强专用桌面入口或快速开始中的 `Start.ps1` 命令。首次启动需要建立关系索引；仅实际创建或 fork 产生的关系会形成树。确认父聊天位于最近聊天或对应项目中。运行 `doctor.ps1` 检查环境，并核对官方包版本：本版实机适配 `26.1027.3384.0`，官方更新可能改变界面或本地数据结构。

如果要继续点击习惯的固定位置，需要先取消旧官方入口的固定，再固定增强入口并调整位置。相同名称或图标不会让旧固定项自动改向。官方“所有应用”、协议链接和自启动仍可能绕过增强，详见[使用指南](user-guide.zh-CN.md)。

启动脚本若提示普通模式仍在运行，请从应用菜单退出，不要强制结束；提示端口被占用或已有另一版增强运行时，先按提示排查或停止原增强。官方窗口可保持原样。手动从 PowerShell 启动通常能看到具体错误。

## 快捷键没有反应？

选中父聊天后使用 `Ctrl+Shift+A`。截图工具等程序可能占用该组合键，可调整冲突软件的快捷键；也可使用聊天菜单中的归档入口。本版没有备用组合键。确认框会列出归档范围；折叠不会排除后代。

## 归档中途停止怎么办？

先查看进度和错误提示。增强逐项提交原生归档，并读取本地归档状态验证；出错时停止后续操作，之前完成的归档不会自动撤销。查看官方应用中哪些聊天已归档，再决定如何处理剩余聊天。不要假定整个操作已完成，也不要重复提交已完成的部分。

## 能级联删除吗？

本版没有级联删除：当前官方原生界面没有可供此功能使用的 Delete 操作。归档与删除是不同操作。

## Stop 和卸载有什么区别？

`Stop.ps1` 移除当前窗口中的增强并停止旁路进程，官方窗口保持打开。卸载还会在身份检查通过后将项目程序目录与专用快捷方式送入回收站，保留项目数据；官方聊天和账户数据不在卸载范围。卸载后正常退出并重开官方应用，临时调试端点才会随原进程关闭。

## 卸载提示快捷方式被修改？

安装与卸载共用入口定义，包括隐藏窗口参数，并识别本项目旧版生成的完整入口。出现此提示，说明目标或参数与这些项目入口不符。卸载会保留快捷方式和程序目录，先检查目标或参数的实际改动，再决定如何处理，不要用覆盖安装绕过保护。

## 升级会覆盖我的数据吗？

安装器拒绝覆盖已有程序目录。先用本版卸载器预览并移除原有项目安装，独立数据默认保留；再用新版本的 `-ReuseData` 复用有项目身份标记的数据。先检查每一步的 `-WhatIf` 输出。自定义目录需在卸载与新安装时分别指定。

## 报告问题时应提供什么？

提供项目版本、Windows 版本、官方 Codex 包版本、所执行的命令、错误文字及可复现步骤。截图和日志可能包含聊天标题、ID、账户或工作内容，分享前请自行检查并移除敏感信息；不要上传账户凭据、数据库或完整个人数据目录。
