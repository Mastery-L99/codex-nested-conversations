# GitHub 发布范围

## 两种下载包

| 下载文件 | 发给谁 | 内容 |
| --- | --- | --- |
| `codex-conversation-manager-0.3.0-preview.6-marketplace.zip` | 使用官方嵌套面板或批量归档的人 | 可登记的本地插件市场、嵌套目录、归档页面和许可证。运行这个插件不需要安装 npm 依赖。 |
| `codex-nested-conversations-0.3.0-preview.6-source.zip` | 需要嵌套侧栏或打算参与开发的人 | 源码、安装脚本、依赖锁文件、测试和双语文档。原列表的嵌套功能需要单独加载界面适配器。 |

发布时为每个 ZIP 提供 SHA-256 校验文件。发行说明应列出适配的 Windows 桌面版本、安装步骤、测试过的入口以及卸载方法。插件页面用户从本地插件市场包开始；需要在原侧栏折叠聊天的用户选择完整安装。[双语安装说明](independent-modules.zh-CN.md)

源码包只收录经过审阅的 Git 跟踪文件。插件市场包只收录官方嵌套和归档面板所需的文件及市场清单。GitHub Release 的下载资源与源标签应指向同一份实现。检查安装和归档行为的方法见[测试说明](testing.md)。

## 内容和署名

项目自写源码采用 MIT 许可。归档页面内嵌的四个第三方依赖适用各自的上游许可。随源码、插件和安装目录保留 `LICENSE`、`NOTICE.md` 及生成页面中的上游声明。[第三方许可](../NOTICE.md)

发布前运行 `npm run audit:release`，检查暂存差异和实际 ZIP 文件列表。源码扫描覆盖高风险文件名、用户绝对路径和常见凭据格式。公开样例只使用演示聊天。官方客户端、账户资料、聊天历史和本地运行数据均在发行范围之外。

## 与官方桌面客户端的关系

独立归档插件提供 `plugin.json` 和 `mcp.json`，在官方桌面插件宿主中打开自己的归档页面。通过 GitHub 分发的本地市场，供用户在自己的客户端手动登记并安装。[插件目录格式](https://developers.openai.com/plugins/build/plugins#plugin-structure)

原侧栏嵌套来自本项目的运行时界面适配器。目前验证过的加载方式是从项目创建的增强入口启动原有客户端。点击官方原图标冷启动并自动显示树仍在研究中。发行说明应说明这一区别，让用户按所需功能选择下载包。
