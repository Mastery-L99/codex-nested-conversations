# 安装、卸载与更新验证

## 0.2.0-preview.1 实机记录

2026-10-30，在 Windows 上从全新的增强安装目录启动，连接的是原官方应用的同一主进程和同一账户。没有安装另一份官方客户端，也没有创建额外 profile。首次运行生成关系数据，嵌套目录显示恢复正常。

停止增强后，增强节点计数 `ownedNodes` 与扁平列表隐藏项计数 `hiddenFlat` 均回到 0。实际卸载把增强程序目录送入回收站，独立数据目录得到保留。测试目录随后通过 Windows 回收站工具清理，日常使用的增强恢复运行。

归档测试使用了两条专门创建的测试聊天，完成一次级联归档；随后新建 fork，关系自动发现后，再通过快捷键路径归档。三条测试聊天的本地数据库 `archived` 值最终均为 1。记录不包含真实聊天 ID 或标题。

快捷键验证覆盖真实应用窗口中的键盘事件、隔离 preload 中的官方消息转发，以及用户实按 `Ctrl+Shift+A` 的范围确认。物理按键最初被第三方截图软件占用；用户关闭冲突项后，确认弹窗包含完整下级并取消了操作。测试聊天的归档提交和数据库结果另行完成验证，没有归档用户的业务聊天。

本版只保留 `Ctrl+Shift+A`。四组运行回归覆盖目录与临时编号映射、归档顺序和中断、快捷键和焦点识别、事件索引；快捷键包含 31 项检查。安装与卸载共 47 项断言，包括快捷方式身份、修改保护、中文说明和 MIT 许可的安装一致性。

默认入口也完成了冷启动验收：Windows 开始菜单中的旧官方固定项被同名启动快捷方式替换。导出布局确认首位只有该快捷方式；用户从它重新打开后看到嵌套列表，官方进程携带本机调试参数，伴随进程自动启动，界面检查无错误。官方“所有应用”、协议和自动启动仍可能绕过这个入口。

原生界面没有提供可用的 Delete 操作，本版没有实现或测试级联删除。官方更新若改变原生 UI 或本地数据结构，需要重新适配并复验。

## 后续版本回归步骤

推荐在 Windows 的独立测试用户下完成一次完整验证，避免测试过程影响日常聊天。生产账户先做只读检测。

1. 运行 doctor.ps1，检查 Node、Python、npm、Playwright 和官方应用发现结果；分别模拟缺失依赖，确认提示后停止。
2. 运行 install.ps1 -WhatIf，检查目录、清单、独立入口与依赖来源；确认没有创建目录、进程或快捷方式。
3. 选择全新安装目录与全新数据目录正式安装。核对安装清单只含自写源码与项目脚本，没有官方安装资源、会话或账户。
4. 第二次安装到同一目录，确认直接停止，不覆盖原安装。对已有同名快捷方式也执行相同检查。
5. 使用增强入口启动，验证仍是同一官方安装和同一账户。临时端点绑定本机地址，所有者为被发现的官方主进程。
6. 新建、派生、归档、恢复聊天，核对嵌套关系、展开偏好、事件更新与快捷键。用户输入和菜单打开时不应触发无关操作。
7. 停止增强，确认样式、监听、快捷键与菜单被清理，官方聊天窗口继续可用。再次启动后功能正常。
8. 卸载 -WhatIf，确认无变化。正式卸载后检查旁路进程已退出，独立入口和程序目录已进入回收站，独立数据目录仍在，官方聊天与账户未变化。
9. 先正常退出官方应用，再按官方入口重开；核对原生列表和临时调试端点关闭状态。
10. 使用 `-ReuseData` 重新安装，确认只复用带本项目数据标记的目录；验证没有重复入口或重复监听。模拟复制失败后，确认半成品仍带有项目标记，能由仓库的卸载器回收。官方更新后记录版本并重复关键功能。

快捷方式被他人修改、安装标记丢失、路径包含重解析点、端点被其他进程占用、停止失败和回收站调用失败时，都应保留现状并报错，不继续删除或覆盖。

语法检查与临时目录安装检查不能替代最终运行模块的实际启动、界面和停止恢复验证。

## 自动安装检查

源码和公开依赖准备齐全后，运行 `npm test`。它只在系统临时目录安装增强脚本，明确禁用快捷方式，不调用运行模块的 Start/Stop，不复制或启动官方客户端。

检查覆盖预演不落盘、完整源码复制、环境变量、重复安装保护、卸载保留数据，以及带身份标记的数据复用。测试结束后把它自己创建的目录送入回收站；失败时保留临时目录供检查。它不使用生产增强目录，也不操作生产进程。

受管理的本机测试可通过 `CNCC_TEST_RECYCLE_SCRIPT` 指定已有的回收站脚本，该脚本接收 `-LiteralPath`，默认使用 `pwsh.exe` 执行，也可用 `CNCC_TEST_RECYCLE_HOST` 指定已安装的 PowerShell 可执行文件。未指定外部脚本时使用项目自身的 Windows 回收站实现。这些设置只影响测试目录清理，不参与普通安装或运行。
